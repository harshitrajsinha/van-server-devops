1. Image is pulled locally into K8s from KinD cluster. Load image from host machine to KinD
```
kind --name go-cluster load docker-image harshitrajsinha/van-server:latest
```
2. While creating db connection string env in deployment.yaml:
- Note database's namespace service name
- Replace host as <db-svc-name>.<db-namespace>.svc.cluster.local  (This is DNS name and will resolve to clusterIP)
- We could also replace with clusterIP directly (but is not practiced in production) 

3. Store DB_URL value in secret when replaced with managed database URL like NEON DB

3. To Run Nginx Ingress Controller

```
helm upgrade --install nginx-ingress oci://ghcr.io/nginxinc/charts/nginx-ingress --namespace nginx-ingress --create-namespace -f nginx-ic-values.yaml
```
